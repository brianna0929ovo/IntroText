# Email your GitHub account link to the bot

## Email your GitHub account link to the bot at `bot@aktash.dev` from your GBC email
- Bot address: `bot@aktash.dev`
- Send the email from your George Brown email. Emails from other domains will be ignored.
- Include your GitHub account link in the email **subject** line.
- Your account link should look like `github.com/YourActualUsername`
- A new repository will be created for you. This repository belongs to the `comp1238f26` organization and the address will look like this:  
`github.com/comp1238f26/lab2-YourUsername`
- The bot will respond within 3 minutes with links to **all** of your lab repositories, including ones from previous weeks. Make sure to pick the link for the lab you want to work on.


![Bot email](img/bot_email_screenshot.png)


## Common issues
- If the repo link in the bot's response is very long and starts with `https://can01.safelinks...`, that's OK; it's a protection mechanism used by Outlook, and this link will automatically redirect to the actual GitHub repo URL.
- If you see a 404 error (not found) it's probably because you are not logged into GitHub in your browser. Log in to GitHub and click the link again.



## GitHub links
- Examples of good GitHub links:
    - `github.com/YourActualUsername`
    - `https://github.com/YourActualUsername`
    - `https://github.com/YourActualUsername/`
    - `https://github.com/YourActualUsername/SomeRepo`
- Examples that will NOT work
    - `YourUsername` - github.com is missing
    - `github.com / YourActualUsername` - spaces around the `/`
    - `github.com/kamrik` - this is the prof's link, not yours
